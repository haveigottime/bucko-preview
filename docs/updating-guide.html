Updating bucko.uk

The whole manual. Ten minutes, once.

The site is a handful of files sitting on GitHub. Cloudflare watches them and republishes bucko.uk every time something changes. You only ever edit one file, and you do it on the GitHub website in a normal browser — no software, no uploading.

The whole job, every time

  1. Open content.js on GitHub.
  2. Click the pencil. Change the words.
  3. Click Commit changes.
  4. Wait a minute. Refresh bucko.uk.

One-time setup

  1. Make a free GitHub account at github.com/signup if you haven't got one.
  2. Tell Rory your username. He'll add you to the site's repo and you'll get an email invite — accept it.
  3. Bookmark this page: github.com/haveigottime/bucko-preview/edit/main/content.js
    That link opens the file already in edit mode. That's 90% of the manual.

Editing the file

content.js is just a list of the band's stuff — gigs, tunes, videos, quotes, links — written out in a slightly strict way. Think of it as a form where the labels are fixed and you fill in the bits between the quote marks.

Three rules keep it working:

  • Text lives inside "quotes". Change what's between them, leave the quotes alone.
  • Every line ends with a comma. Copy a line, the comma comes with it.
  • Dates are "YEAR-MONTH-DAY", like "2026-09-12".

When you're done, scroll up and hit the green Commit changes button (top right). A little box pops up — just hit Commit changes again. Done. Cloudflare picks it up within a minute or two.

If the site goes blank

You've lost a quote mark or a comma somewhere. Nothing is broken for good. On the same GitHub page click History (top right), click the version before yours, then Revert — or just message Rory. The site is back the moment it's fixed.

The jobs you'll actually do

Add a gig

Find the gigs: section. Copy one of the gig blocks — from its { to its }, — paste it underneath, and change the details. Order doesn't matter; the site sorts by date and hides gigs automatically the day after they happen.

gigs: [
  {
    date:    "2026-09-12",
    event:   "Crawlchella",      // festival / night name, or "" for none
    venue:   "The Grove",
    city:    "Nottingham",
    time:    "14:30",            // doors / stage time, or ""
    tickets: "https://www.gigantic.com/...",   // "" if free or not on sale yet
    sold:    false,
  },
  {
    date:    "2026-11-07",
    event:   "",
    venue:   "Rough Trade",
    city:    "Nottingham",
    time:    "19:30",
    tickets: "",
    sold:    false,
  },
],

Sold out? Change sold: false to sold: true. It gets a stamp.
Free entry? Leave tickets: "" empty and it says so.

Add a single or EP

Find releases:. Add a new line at the top (newest first). The only fiddly bit is the Spotify code: open the release on Spotify, hit Share → Copy link, and take the bit after open.spotify.com/.

// https://open.spotify.com/album/5byAofE0XSGLIUZEU8VSV2?si=...   →   "album/5byAofE0XSGLIUZEU8VSV2"
releases: [
  { title: "New Tune", type: "Single", date: "2026-10-02", spotify: "album/XXXXXXXXXXXXXXXXXXXXXX", appleMusic: "" },
  { title: "Bucko",    type: "EP",     date: "2026-08-14", spotify: "album/5byAofE0XSGLIUZEU8VSV2", appleMusic: "https://music.apple.com/..." },
  ...

Ignore anything after ?si= in the Spotify link. Apple Music link is optional — paste the whole URL or leave it "".

Add a video

Find videos:. The code is the bit after youtu.be/ or after watch?v= in the YouTube link.

// https://youtu.be/1jp16cV-z8E   →   "1jp16cV-z8E"
videos: [
  { title: "Maracas (Live at The Grove)", youtube: "AbCdEfGhIjK" },
  { title: "Terraces (Music Video)", youtube: "1jp16cV-z8E" },
],

The first video in the list is the one that shows on the press page.

Change the bio, quotes, FFO or taglines

They're all just text in quotes — tagline, lines, bio, quotes, ffo, featured. Each paragraph of the bio is its own quoted line. To add a press quote, copy a { text: "...", who: "..." }, line.

Add the WhatsApp link / change any link

All in links:. Paste the WhatsApp broadcast invite into whatsapp: "" and the button appears on the contact page by itself. Same for Instagram, TikTok, the shop, etc.

Switch the shop on

Right now every Shop link goes to a "Coming soon" page. When the Shopify store is live, find shopLive: false in links: and change it to shopLive: true. Every Shop link on the site then goes straight to shop.bucko.uk.

New press photos or files

This is the one job that needs a second step, because it's a file not words:

  1. Go to the assets folder, click Add file → Upload files, drop the photo in, commit.
  2. In content.js, add it to downloads: —
    { label: "Press photo 2027", file: "assets/bucko-2027.jpg" },

Keep filenames simple: lowercase, no spaces, e.g. bucko-live-2027.jpg.

Two things still to switch on

The contact form

Right now the form opens the visitor's email app with the message pre-filled — works, but clunky. To have messages land straight in booking@bucko.uk:

  1. Go to web3forms.com, enter booking@bucko.uk, and they email you an "Access Key". Free, no account needed.
  2. Paste it into content.js: web3formsKey: "paste-it-here",

WhatsApp broadcast

Once the channel exists, paste the invite link into links.whatsapp. That's it.

Don't touch

Everything other than content.js and the assets folder is the machinery — index.html, css, js. You can't hurt anything by looking, but if the look of the site needs changing, that's a Rory job.

Stuck? Message Rory. Nothing you do in content.js is permanent.
